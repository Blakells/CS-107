## Database examples, schema & types 
- strictly defined databased are computer structures that save, organize, protect and deliver data 
- The simplest form of database is a text database 
- Desktop database programs are another type of database that is more complex than a text database but intended for a single user. examples would be excel, or microsoft access 
- Relational databases are the most common database systems. They include SQL servers, Oracle databases, Sybase, Informix, and mySQL. RDBMS (Relational Database Management System) features much better performance for managing data over desktop database programs 
- RDBMS allow THOUSANDS of users to work with the data at the same time, created advanced security for access to the data. 
- RDBMS store data in columns and rows, which make up a table. A table is like a spreadsheet. 
- A set of tables makes up a schema, and and number of schema create a database. Many databases can be created on a single server
