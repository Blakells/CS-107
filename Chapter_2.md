# Chapter 2 - Relational Database Model 
-----------------
## 1.1 - What is an entity in a database 
- An **entity** is a container designed to store and delineate information that is important to the goals of the project
- An entity doesn't have to *do* anything 
- An **ERD (entity relationship diagram)** allows database admins to view the relationships between several entities 
## 1.2 - What is an attribute in a database 
- **Relational Databases** are electronic tables that look like spreadsheets and house large amounts of interconnected data.
